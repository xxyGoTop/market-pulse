# Market Pulse 图标设计资源

本压缩包包含 Market Pulse 股票提醒桌面工具的图标设计总览，以及按功能区域裁切的 PNG 参考图。

## 文件说明
- `Market_Pulse_图标设计总览.png`：完整设计稿（1536 × 1024）。
- `01`～`08`：按大盘状态、股票分组、界面功能、状态提示、通用功能、股票操作、应用/托盘、主题/颜色规范分区裁切的参考图。

## 开发提示
这些文件是设计参考 PNG，并非独立 SVG 图标集。若要在 Vue 组件中逐个调用，建议根据此稿重新绘制/导出独立 SVG，统一命名并为亮暗主题提供适配版本。桌面应用正式图标还需要按 Tauri 的 Windows ICO 和 macOS ICNS 要求分别生成。
